# GameZone Retro

Página promocional de uma loja fictícia especializada em jogos e consoles clássicos.

-----


##  Sobre o Projeto

O **GameZone Retro** foi desenvolvido como parte de um mini desafio de **HTML**, com o objetivo de praticar os principais conceitos de estruturação de páginas web.

A página apresenta uma loja fictícia de jogos retrô, contendo informações sobre consoles disponíveis, preços de jogos, imagem temática e links de navegação.

##  Objetivo

Criar uma página HTML simples, organizada e funcional, utilizando os principais elementos aprendidos durante as aulas.

-----

##  Recursos Implementados

- Título e textos formatados
- Lista de consoles disponíveis
- Links de navegação
- Imagem temática
- Tabela de jogos e preços
- Emojis para personalização da página
- Estrutura básica de HTML

----------

##  Conteúdo da Página

A loja apresenta alguns consoles clássicos, como:

- Nintendo (NES)
- Super Nintendo (SNES)
- Sega Genesis
- Atari 2600

------------

##  Aprendizados

Com este projeto, foi possível praticar:

- Estrutura básica de um documento HTML
- Uso de títulos e parágrafos
- Listas ordenadas e não ordenadas
- Inserção de imagens
- Criação de links
- Criação de tabelas
- Formatação de textos
